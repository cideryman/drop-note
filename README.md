# ☕ PourOver Pro - 모바일 전용 커피 드립 계산기 & 타이머

> **매번 원두량이 바뀔 때마다 물량을 계산하는 번거로움을 단번에 해결해주는 스마트 모바일 드립 커피 조교**  
> 모바일 브라우저 하나로 비율 자동 스케일링부터 실시간 저울 목표 중량 가이드, 카운트다운 알림까지 완벽하게 지원합니다.

---

## 🌟 주요 기능 (Key Features)

### 1. ⚖️ 원두량 기반 자동 비율 계산 엔진
- 사용자가 조절한 원두량($g$)에 따라 기준 레시피의 **단계별 물량, 총 물량, 얼음량**이 실시간 자동 계산됩니다.
- 시간, 물 온도, 분쇄도 기준, 하리오 스위치 개폐 여부 등 커피의 고유 특성 변수는 고정 보존됩니다.

### 2. 🧊 핫 / 아이스(Hot & Ice) 분리 스케일링
- 아이스 레시피 선택 시 전체 물량 중 서버에 담아둘 얼음 비중(35~40%)을 원두 비율에 맞춰 정밀 스케일링합니다.

### 3. ⚠️ 스마트 분쇄도 경고 알림 (Edge Case Helper)
- 입력 원두량이 기준 대비 20% 이상 증가할 경우, 커피 층(Bed)이 두꺼워져 물 빠짐이 느려지는 것을 막기 위해 **"분쇄도 +1~2클릭 굵게 조절"** 안내 카드가 출력됩니다.

### 4. ⏱️ 실시간 인터랙티브 타이머 & 저울 누적 중량 가이드
- **저울 목표 중량(Target Scale Weight) 대형 표시**: 전자저울을 보며 물을 부을 때 영점을 매번 누르지 않아도 직관적으로 저울 수치를 맞출 수 있는 누적 중량(g)을 함께 제공합니다.
- **실시간 단계 하이라이트**: 현재 주입할 물 용량, 물 온도, 스위치 개폐 상태 및 다음 단계 프리뷰 제공.

### 5. 📱 추출 전용 실전 디테일 (User Experience)
- **화면 꺼짐 방지 (Screen Wake Lock API)**: 드립을 내리는 3~4분 동안 스마트폰 화면이 꺼지지 않도록 자동 제어됩니다.
- **카운트다운 비프음 & 진동 (Web Audio API & Vibration)**: 단계 전환 3초 전 '띱-띱-띱-띵!' 오디오 사운드와 손끝 진동으로 물 붓기 타이밍을 알려줍니다.

## ☕ 기본 탑재 레시피 프리셋

1. **하리오 V60 4:6 (카스야 테츠)**: 산미와 단맛, 바디감의 균형을 맞추는 5단계 추출 레시피
2. **하리오 스위치 스위트 레시피**: 침출과 투과를 결합하여 극상의 단맛을 끌어내는 레시피
3. **제임스 호프만 Ultimate V60**: 뜸들이기 후 60/40 균등 분할 주입 표준 레시피
4. **아이스 급랭 드립 (3:7 얼음)**: 서버에 얼음을 가득 담고 진하게 추출하는 여름 전용 레시피
